# Wings II plan: a flyer for every faction, and abilities in the air (2026-11-16, at 0.19.0)

> **Status: plan only.** Nothing here is built. Owner decisions are listed in section 7.

## 1. Why

Air shipped in 0.18 with four flyers (Kite, Hawk, Ember balloon, Swift glider). A review of the data
on 2026-11-16 found the four roles distinct, but:

| Gap | Evidence |
|---|---|
| Wardens and Veil have no flyer of their own | `balance.json` `factions.<id>.extra`: only meridian, ashfall, sunward have `hq` entries |
| Only the Hawk can fight in the air | `hits_air` flyers: hawk only |
| No flyer has an ability | no `ability` on kite, hawk, balloon, glider; every ground combat unit has one |
| Nothing is carried | no load/unload orders exist |

## 2. Scope

| Release | Content | Size |
|---|---|---|
| **0.20.0 "Wings II"** | Measure first. A. Aegis (Wardens) and Wraith (Veil). B. One ability each for Hawk, Balloon, Glider. C. AI use, field guide, hints, Vietnamese, docs. D. Ground units for the weaker factions, kept only if the bench improves. | this plan |
| 0.21 (separate decision) | Air transport: carries infantry over rivers and cliffs | section 8, not planned in detail |

Out of scope: changing the air cap (4), new anti-air buildings, new maps, campaign missions.

## 3. Design

All numbers are starting values in `src/balance.json`; the bench in section 6 may move them.

### A1. Aegis (Wardens): support flyer, no weapon

| | Value | Reason |
|---|---|---|
| Role | "Air support" | first flyer that helps instead of hurting |
| HP / shield | 260 / 80 | sturdy, like Wardens units |
| Speed | 3.0 | slower than the Hawk (4.8): cannot keep up with a raid |
| Weapon | none | |
| Aura | units of its team within 6 m recharge shield 2.5× faster; does not stack (two Aegis = one aura), and does not add to a Pylon | the Pylon aura (`sim/traits.js`, `e.shieldRate`) does this for buildings (1.5×); the Aegis extends the same lazy field to units. Shield only, so it does not double the Wardens self-repair |
| Cost / supply / time | 200 alloy, 125 energy / 3 / 24 s | same bracket as the Hawk |
| Requires | Command core level 2 | |
| Ability | none in 0.20 | the aura is its job |

Risk: Wardens already win too often in the faction bench (BALANCE.md). The aura restores shield
only, never health, and the bench must not move Wardens' win share up by more than 3 points; if it
does, lower the rate first, then the radius.

### A2. Wraith (Veil): cloaked striker

| | Value | Reason |
|---|---|---|
| Role | "Air stalker" | |
| HP / shield | 140 / 40 | fragile once seen |
| Speed | 5.6 | |
| Weapon | 22 damage every 1.6 s, range 6, ground only, 1.5× to mechanical | a first strike, weak sustained fire |
| Cloak | `cloak: true`: hidden after 3 s without firing (the Veil rule, `traits.farsight.cloak_delay`); revealed by anything with `detect` (Kite 8 m) and by Veil-style reveal ranges | reuses `isVisible`, so renderers, minimap and sound need no change |
| Cost / supply / time | 175 alloy, 100 energy / 2 / 22 s | |
| Requires | Command core level 2 | |

Rule to add: a cloaked flyer is seen by `airSeenBy` only when it is not cloaked for that team.
Test both orders (cloak then fly into sight; fire, then re-cloak).

### B. Abilities for the three combat flyers

Each reuses an existing ability rule in `sim/tactics.js`; only data and one targeting check are new.

| Flyer | Ability | Rule reused | Values |
|---|---|---|---|
| Hawk | **Strafe**: fire twice as fast for 4 s | `focus` (timed, `interval`) | cooldown 40, duration 4, interval 0.35 |
| Ember balloon | **Firedrop**: burn the ground below for 6 s | `burnline` zone, cast at own position (range 0) | cooldown 45, radius 3, 8 damage per second |
| Swift glider | **Dive**: double speed for 3 s | `dash` | cooldown 30, duration 3, speed 2 |

Checks: abilities are refused in the ford for walkers only (a flyer is never "in the ford");
Firedrop needs no sight gate (it lands under the balloon); zones never hurt flyers.

### D. Ground units that help balance (owner, 2026-11-16: allowed where measurement supports it)

**Measure first (package W0).** The last recorded round robin is from 0.15.0, before air and
Round 3: Wardens 71%, Meridian 58%, Ashfall 58%, Sunward 38%, Veil 25%; worst pairs Ashfall–Veil
11/12, Sunward–Wardens 2/12, Wardens–Veil 10/12. W0 re-runs `npm run bench:factions` at 0.19.0 and
adds two readings the table lacks: *when* each loss happens (match length per pair) and *what* the
loser had on the field. A unit can only fix a loss that happens after the unit can exist.

**Room for a unit.** The Barracks trains four units (full). The Foundry trains three (Breaker,
Engineer, Battle tank) and also holds four research items, drawn as research slots. A fourth
Foundry unit is the only place for an addition, and W4 must first show at 390x844 and 844x390 that
it fits beside the research slots with 44 px tiles and no scroll. If it does not fit, the unit
replaces a base unit for that faction (a `swap`, as the factions do today) instead of being added.
Wardens have no Medic and no Engineer, so they have room in both buildings.

**Candidates, each with the loss it is meant to fix.** Build a candidate only if W0 confirms its
loss pattern; keep it only if the bench improves (rule below).

| Faction | Unit | Tile | Sketch | Loss it targets |
|---|---|---|---|---|
| Sunward | **Lancer** (siege) | Foundry L2 | range 12, 26 damage every 2.4 s, 2× to buildings, 110 HP, slow to turn; 175/75, supply 2 | Sunward–Wardens 2/12: raiders cannot crack towers, Pylons and Walkers (range 13) |
| Veil | **Hexer** (control) | Foundry L1 | no damage; ability *Snare*: enemies in 4 m move 40% slower for 6 s (cooldown 30); 90 HP, 125/50, supply 2 | Veil against swarms and rushes that reach its ranged line (Ashfall 11/12) |
| Veil | early defence by numbers, not a unit | - | if W0 shows Veil dies before a Foundry can stand (about 2 minutes), a Foundry unit cannot help: tune Shade cost/train time or the first tower instead | Ashfall's early rush |
| Ashfall, Meridian | none | - | inside or near the band | - |
| Wardens | none on the ground | - | already above the band; the Aegis is their only addition and is gated by the bench | - |

**Keep or drop rule.** A candidate stays only if, on the same 120-match bench: its target pair moves
towards 6/12 by at least 2 wins, pair deviation does not rise, and no pair that was inside 35 to 65%
leaves it. Otherwise its data and model are removed before release and the result is recorded in
BALANCE.md. At most two passes of number tuning per unit (BALANCE.md: more passes moved little).

Each kept unit needs: a `balance.json` definition, a faction `extra.foundry` entry, a Blender model
on the kit (ground-unit budgets in ASSET_PIPELINE.md), a field guide entry, Vietnamese text, an AI
rule for when to train it (`sim/ai-counter.js`), and for the Hexer one new timed effect (`slowed`,
lazy, in `sim/tactics.js` and `moveSpeed`).

### C. Around them

- **AI** (`sim/ai-counter.js`): the "own flyer" rule already reads `factions.<id>.extra.hq`, so both
  new flyers are trained with no new code. Add: an Aegis follows the largest group (like the Kite
  spotter, but level with it, not ahead); the AI casts flyer abilities through the existing
  auto-cast path for computer players.
- **Flak research and the Kite** stay as they are. The Kite's `detect` is the Wraith's counter and
  must be said in both descriptions.
- **Client:** model roster entries, rotor/part animation names, card lines ("Air", "Cloaked",
  "Shields allies"), an aura ring for the Aegis when selected (reuse the reach-ring drawing), ability
  tiles (already generic), field guide entries, one first-time hint for the Aegis aura.
- **Text:** every new string in `locales/vi.json`; unit descriptions follow the existing pattern.
- **Models:** two new builders in `tools/blender/generate_air.py` on the shared kit, 900 to 1,400
  triangles each (the four existing flyers are in that range), same vertex attributes, rotors or
  fans as named spin parts. Aegis: a wide ring hull with a glowing core. Wraith: a thin dark dart
  with swept fins. The owner refines them later, as with the first four.

## 4. Rules that must hold

- The sim hash `d071360b` stays unchanged: no new always-present state. The aura and the cloak write
  only to units in matches that have these flyers.
- Every action through `sim.command`; a save taken with an Aegis aura running and a cloaked Wraith
  loads and replays identically.
- Nothing visual or audible reveals a cloaked Wraith; it is drawn for its owner as other cloaked
  units are.
- Phone: the Command core keeps four tiles. Each faction still has exactly one extra flyer tile
  (Harvester, Flak, Kite, own flyer), so the layout does not change.
- Draw budget: `air-battle-eco` stays within its 118-draw limit with the new models.
- Text at least 11 px, taps at least 44 px, no sideways scroll at the three viewports.

## 8. Later: the transport (not planned in detail)

A slow unarmed carrier for up to 4 infantry, for all factions, trained at Command core level 3.
New work it needs: `load` and `unload` commands, carried units in the save format (lazily), AI drops,
a phone control for unloading, and a fifth-tile question at the Command core (it would replace
nothing today: four tiles are taken). It adds the most new play (drops behind a blown bridge, onto a
plateau) and is the largest piece, so it gets its own plan after 0.20 is played.
