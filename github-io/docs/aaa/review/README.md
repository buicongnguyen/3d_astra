# Faction model approval sheets

Package 2.2 candidates. These are original assets generated by the repository's Blender 4.5 toolkit, rendered from the exported GLBs at the game camera angle. Each sheet labels the unit/building IDs. Greyscale removes faction color to expose silhouette differences.

| Faction | Color sheet | Greyscale sheet | Intended shapes |
|---|---|---|---|
| Ashfall | [Color](ashfall-color.png) | [Greyscale](ashfall-greyscale.png) | Asymmetric patched armor, exposed frames, tall exhausts and salvage gantry |
| Sunward | [Color](sunward-color.png) | [Greyscale](sunward-greyscale.png) | Wheels, broad low awnings, round water tanks |
| Wardens | [Color](wardens-color.png) | [Greyscale](wardens-greyscale.png) | Smooth machines, orbital rings, one eye light, no crew |
| Veil | [Color](veil-color.png) | [Greyscale](veil-greyscale.png) | Narrow hoods and split cloaks, tall masts, lens discs |

The owner approved all four faction looks in chat on 2026-11-11. All twelve portraits are appended after the original thirteen cells. Approval is for the look; gameplay traits and balance still belong to packages 2.3 onward. No mission or skirmish roster has been switched to these models yet.

## Export checks

Every mesh has POSITION, NORMAL, TEXCOORD_0 and COLOR_0; team materials remain recolorable. Infantry/Rider leg pivots, Scorcher/Walker weapon parts and the Drone hover marker are retained. No model uses gltfpack quantization. Repeated faction units will use the existing instance batches and will not cast shadows; buildings may cast shadows.

## Reproduce

From github-io, using the installed Blender 4.5 executable:

```
blender --background --factory-startup --python tools/blender/generate_assets.py -- --factions
blender --background --factory-startup --python tools/blender/preview_factions.py
```

Source library: assets/source/frontier-factions.blend. Export metadata: public/models/manifest.json. Validation: tests/assets.test.js. Portrait regeneration and roster activation follow owner approval.
