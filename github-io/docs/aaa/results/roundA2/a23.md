# A2.3 • Weapon impacts

Ground rifle volleys now produce one expanding, normal-blended pressure ring at arrival, including multi-round faction weapons. Its minimum diameter is 32 CSS px and it dissipates in 0.42 seconds. Aircraft and support orders produce zero ground rings. Reduced motion and Combat motion off suppress the new ring and moving tracer. The presentation uses existing capped pools and adds zero meshes.

The standard Ranger tracer now has a dark moving underlay on bright terrain. Faction tracer strokes have a 4 CSS px width floor before atlas masking. The flak sheet footprint rises from 44 to 56 CSS px minimum. Satellites have a 13 CSS px minimum separation at phone zoom. The procedural flak fallback now uses the same real-time flash limiter as the loaded sheets (340 ms interval, at most three grants in a rolling second).
