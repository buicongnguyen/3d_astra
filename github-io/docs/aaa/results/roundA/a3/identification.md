# Reading the 24 px unit board

[Live field samples](gameplay-24px.png) show friendly grass, opposing grass, friendly sand and opposing sand for each row. Use the images at native size. Cover the names to try identification. The observations below describe visible cues in these captures. Player recognition rates require a blind test.

| Unit | First cue visible at 24 px |
|---|---|
| antitank | A long pale launcher crosses the small infantry body. |
| balloon | The round envelope and underslung gondola read in both colours. |
| breaker | Two broad parallel metal sections fill most of the tile. |
| carrier | A broad rectangular vehicle with a stepped rear. Its outline is close to the gunner's. |
| drone | The round disc separates it from infantry. |
| engineer | A compact tool-bearing body. The tool is harder to distinguish on sand. |
| glider | Long swept pale wings. |
| gunner | A tall upper housing on a rectangular chassis. |
| hawk | A broad wing and two engine openings. |
| ironsovereign | A wide, low, heavily plated boss. Its body is difficult to separate from the second Sovereign at this size. |
| ironsovereign2 | A similar plated boss. The lighting and terrain affect identification. |
| ironvanguard | A bulky two-legged silhouette and heavy shoulders. |
| kite | A slim flying body with prominent rotor blades. |
| medic | Small white helmet and bright medical armour. |
| rampart | A square angular armoured body. |
| ranger | The projecting rifle is its most legible feature. |
| rider | Narrow diagonal profile. Fine detail blends into the sand. |
| scorcher | A compact vehicle with a team-colour upper housing. |
| scrapper | Narrow shoulders and a small upright silhouette. |
| shade | A dark, narrow silhouette and violet highlights. |
| stalker | Long projecting limbs. On grass its colour can resemble the shade. |
| tank | A broad chassis with a long bright barrel. |
| vanguard | A large shield gives one side of the figure extra width. |
| wagon | Broad pale roof with a red medical cross. |
| walker | Several spread legs around a high central body. |
| watcher | Tall narrow body with a small violet highlight. |
| worker | Bright yellow equipment distinguishes the friendly worker in these captures. |
