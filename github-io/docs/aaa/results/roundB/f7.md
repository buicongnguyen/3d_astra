# F7 / quarter-size painted weapon effects

The Vanguard, Ranger and Anti-tank shots cross the full distance to the target. The Ranger's painted streak is especially subtle against pale bridge decking. The Barracks collapse exposes the infantry beside the roof on phone and desktop. The fixed, translucent circle at the bridge is visible before firing and in all three builds.

[Phone comparison, 390×844](f7/phone.webp)  /  [Desktop comparison, 1440×900](f7/desktop.webp)  /  [Painted phone atlas poses](f7/atlas.webp)

Each sheet compares live Round A (9cc366b), F0/F6 (3d88419) and F7. Five fixtures use the same map, units, camera, local visual seed, two shot-relative times and viewport. Vanguard supplies the basic rifle case. Anti-tank fires a direct-hit rocket. The phone uses Chrome touch emulation with DPR 2, and the desktop uses DPR 1. Crops are displayed at their CSS dimensions.

| Effect | Gameplay result |
| --- | --- |
| Rifles and heavy projectiles | VFX2 warm/cyan streaks and shell/rocket/missile noses on both device tiers. Length and width use 0.25× live values after the zoom floor. Contact sparks last 50 ms and fit within half the target width. |
| Splash | Shell, splash rocket, artillery and bomb retain their distinct palettes. Each uses a quarter of its original live extent, capped at twice target width. The shell animates its original white-hot star. The original ring artwork was removed from the packed sheets. The F6 bright core lasts 50 ms. |
| Flame, beam and support | A loaded atlas draws one flame jet. The rail and laser use a tiled beam and caps. The medic uses the green strip with a low-opacity glint at the recipient. Repair uses a tinted thin strip and wrench. Support reaches the target and caps the strip width at 0.16 m. |
| Ground and air | Terrain-coloured puffs use normal blending, quarter size and 35% initial opacity. The walker foot retains dust and debris. Direct rockets make a contact spark, and the air missile uses its first four painted poses. Direct impacts leave no scorch. |
| Accessibility and gameplay | The real-time flash gate, reduced-motion branch, selected-target priority, particle governor and disabled camera shake remain active. Changes are confined to rendering, atlas production and tests. |

## Checks

The full unit suite passed 1,113 tests, with 28 skips and zero failures. Both release atlas files fit the existing atlas dimensions and UV layout. The desktop texture is 451,990 bytes, and the phone texture is 238,238 bytes.

The release build passed. All 34 render-budget scenarios passed. The mixed-weapons Eco scene used 108 p95 draws with zero unloaded models or fallbacks.
